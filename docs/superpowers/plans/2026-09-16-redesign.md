### Supabase schema

`posts` (id uuid pk, slug unique, title_en not null, title_hi/summary_en/summary_hi/body_en/body_hi default '',
date, place, tags text[], yt, media jsonb [{path, type, alt_en, alt_hi, width, height}], live default false,
deleted_at, created_at, updated_at + trigger). Partial index on (date desc) where live and not deleted; GIN on tags.
`editors(email pk)` + `is_editor()` security-definer. RLS: anon select live and not deleted; authenticated editors
full access. Storage bucket `media` (public read, 20 MB, jpeg/png/webp/mp4, editors write), paths `posts/<slug>/<uuid>`.
Nothing hard-deletes. Seed upserts the three built-in posts by slug (`silkyara-open-letter`, `shriyantra-island`,
`rampur-tiraha`); `mergePosts` keeps the site correct before and after seeding.

## Risks and mitigations

- SplitText and Devanagari conjuncts: words for Hindi, characters for English; `aria:'auto'` keeps headings readable.
- Tiro has only weight 400: hierarchy by size, `font-synthesis:none`, italics from the real italic face.
- GSAP size: imported only inside `.client` leaves behind `next/dynamic`; T13 asserts it is absent from first load.
- No Supabase in this container: null-client fallback, unit tests offline, admin E2E gated.
- ScrollTrigger across route changes: `useGSAP` revert on unmount, one refresh on pathname change.
- Flip with no state (deep link, back/forward, reduced motion): CSS fade; state cleared after use.
- Sutra red is about 3.2:1 on the dark ground: lines, underlines and display sizes only; the contrast test enforces it.
- Theme flash: pre-paint head script; `color-scheme` per theme.
- Owner-side prerequisites: Vercel project, Supabase project, editor email list, painting credit and rights.
